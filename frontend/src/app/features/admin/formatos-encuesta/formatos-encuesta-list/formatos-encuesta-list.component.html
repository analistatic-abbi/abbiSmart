Cómo debe ser el archivo

  • Use Excel (.xlsx) o CSV (máx. 2 MB).
  • Incluya fila de encabezado con columnas: seccion, pregunta, subseccion, requiere_calificacion.
  • requiere_calificacion: use si / no (también acepta 1/0, true/false).
  • Varias filas con la misma sección y pregunta agrupan ítems (subsecciones) bajo esa pregunta.
  • El nombre del formato se define arriba; no va dentro del Excel.
  • Cada pregunta: máximo 500 caracteres.
Ejemplo: 
seccion,pregunta,subseccion,requiere_calificacion
Sección I,¿Cómo calificarías el cumplimiento de ANS?,,si
Sección II,¿Cómo calificarías la comunicación?,Disponibilidad,si
Sección II,¿Cómo calificarías la comunicación?,Capacidad de respuesta,si
Sección V,¿Qué aspectos positivos destacaría?,,no

También se acepta el formato legado (una pregunta por fila en la columna A, sin encabezado).
