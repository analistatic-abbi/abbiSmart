Cómo se calcula este reporte

El reporte toma las proyecciones del país de sesión con año proyectado igual al seleccionado y mercado General u Objetivo. Las proyecciones eliminadas o sin mercado no entran al comparativo (aunque se informa cuántas quedaron fuera).

De dónde salen los datos

  • Proyecciones: registro en el módulo de proyecciones (estado, mercado y vínculo al proceso resultante, si existe).
  • Proceso resultante: proceso al que se materializó la proyección (si está vinculado y no eliminado).
  • Adjudicación: se considera ganada si el proceso resultante está en estado Adjudicado o tiene la marca de adjudicación.

Cómo se clasifica cada proyección

  • Ganada: tiene proceso resultante vigente y ese proceso fue adjudicado.
  • Se materializó, no se ganó: tiene proceso resultante vigente, pero ese proceso no está adjudicado.
  • Nunca se materializó: no tiene proceso resultante y la proyección está en estado Cerrado.
  • Pendiente / en curso: aún no se puede resolver (por ejemplo, sigue abierta, o el proceso vinculado es inconsistente). Estas no entran en los porcentajes.

Cómo se leen los porcentajes

  • Los tres primeros porcentajes (% nunca materializó, % materializó y no ganó, % ganó) se calculan solo sobre proyecciones resueltas (excluyen pendientes).
  • % Ganadas de las materializadas usa solo las que sí se materializaron (ganadas + materializadas no ganadas) y muestra la tasa de éxito cuando la oportunidad llegó a proceso.

La comparación General vs Objetivo ayuda a evaluar si las proyecciones marcadas como Objetivo tuvieron mejor desenlace real que las de mercado General en el mismo año.
